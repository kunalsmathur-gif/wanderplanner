# Demo clips

Drop the four recording clips here, named exactly:

- `beat1-cold-open.mp4`
- `beat3-the-loop.mp4`
- `beat4-honesty-inset.mp4`
- `beat5-accountability-inset.mp4`

`demo-deck.html` looks for these paths on load and swaps each "DROP VIDEO HERE"
placeholder for the clip. A slot shows a "Click for fullscreen" hint on hover
once it has been detected — confirm all four do before recording.

Record on desktop at 1920×1080, silent (narration is live, once, over the whole
deck). Trim each clip to roughly its beat's runtime.

`.mp4` files here are gitignored — they are large, and each is regenerated per
recording session rather than versioned.
